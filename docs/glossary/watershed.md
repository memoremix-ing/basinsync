# Watershed

A *Reservoir*[^][reservoir] within a *Basin*[^][basin] that ingests
*CommitMarkers*[^][commit-marker] to arrange in *Flow*[^][flow]
*Epilogues*[^][epilogue]. Its *Timeline*[^][timeline] records their state changes;
API responses identify that log as `timelines.watershed`.
