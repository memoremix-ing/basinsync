# B-tree

A balanced ordered index whose branches retain key/value pairs. Packed logical
branches form *basin nodes*[~][node]; mirrored bounds and summaries permit pruning. See the *structure tutorial*[~][diy/0zg6/261120-basin-node-stdlib/0zg7/261123-b-tree].
