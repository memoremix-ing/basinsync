# Vector

A bitmapped, ordered sequence with bigint indices and optional holes. Packed
logical branches form a versioned graph of *basin nodes*[~][node]. See the *structure tutorial*[~][diy/0zg6/261120-basin-node-stdlib/0zg7/261123-bitmapped-vector-trie].
