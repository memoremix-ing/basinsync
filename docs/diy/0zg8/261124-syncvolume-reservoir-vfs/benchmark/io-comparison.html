Implemented: revision/capability-bound disk caching, immutable verified bytes, resolved file cursors, one-pass eager traversal, bounded GET lookahead, sibling PUT batches, and independent file workers. Root publication waits for every dependency; failures drain in-flight work.

Packing remains configurable. Ordinary packing favors whole-file recovery; smaller objects favor frequent backups. The experimental default stays at 1,280 values. Reported budgets are count budgets, not guaranteed group sizes.

One checksum format: TypeScript, Rust and Go now use CRC64NVME summaries (eight big-endian bytes plus byte count); SHA-384 still protects stored objects. Rust also compiles for Wasm.

Recovery starts cold. Backup follows full hydration and changes one primary row plus a companion counter. A 128 MiB disk cache retains encoded objects; raw pages remain on disk. The server's KernelSpace backup/promotion integration remains deferred.
