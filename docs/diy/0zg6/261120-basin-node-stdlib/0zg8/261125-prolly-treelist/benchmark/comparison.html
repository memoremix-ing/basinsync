Keyless byte treelists versus byte tries

Matched file diffs, independent patch reconstruction. 1,224 measured cases, including a 12-location sweep.

Recommendation: pursue mixed/run-aware, keyless treelists for arbitrary byte editing; keep the current page-trie VFS default. Tight fixed-page tries remain competitive for aligned overwrites and dispersed writes. Confidence: moderate; generated files and a modeled link are not a production corpus or live S3.
