Recommendation: explicit path updates in the core; optional Proxy syntax for suitable UI editing. Proxies reduce copying versus whole-value drafts, but do not beat explicit path-copying here.

Proxy drafts require more reflection, lifetime and array rules. Bytes are atomic read-only facades; whole-value drafts permit ordinary byte edits but copy payloads. Inputs remain immutable. Native cloning is a fixture-only control and cannot clone protocol Symbols.

161 tests, 234 cross-language cases and live storage/restart integration pass. Strong evidence for these tested semantics; performance conclusions are specific to this workload/runtime.
